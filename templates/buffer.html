Đổi Access Token Buffer (Nick mới)

Dán Access Token của tài khoản Buffer mới vào đây để hệ thống tiếp tục gọi API thật. File .env sẽ được tự động cập nhật.

Mẹo: Bạn cũng có thể sửa trực tiếp BUFFER_ACCESS_TOKEN trong file .env rồi bấm "Kiểm tra Quota".
