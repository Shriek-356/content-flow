1. MỤC TIÊU & TỔNG QUAN NÂNG CẤP 2 NGÀY VỪA QUA

Trong 2 ngày làm việc vừa qua (13/08 - 15/08/2026), Phòng IT đã thực hiện đợt tái cấu trúc quy mô lớn cho hệ thống Content Automation Flow. Mục tiêu cốt lõi là chuyển dịch hoàn toàn từ quy trình render HTML/Puppeteer địa phương sang Quy trình sinh ảnh AI Cloud-Native thuần túy (AI Image Generation Pipeline), đồng thời tối ưu hóa bộ sinh nội dung văn bản đạt tốc độ phản hồi cực nhanh với chi phí tối thiểu.

Hệ thống mới giải quyết triệt để các thách thức kỹ thuật: hỗ trợ mỗi slide chứa tới 2 ảnh thô đính kèm (Multi-Image Slides), cho phép AI tự do cắt xén/tách nền ảnh thô (Dynamic Image Editing/Cropping), ép xuất chuẩn cấu trúc JSON Object bằng GPT-4o-mini (~18 VNĐ/bài) và hoàn thiện node JavaScript chuẩn hóa tự động ghi dữ liệu vào Google Sheet 24/7.

2. 5 CẢI TIẾN KỸ THUẬT CỐT LÕI ĐÃ HOÀN THÀNH

Hạng mục Kỹ thuật Giải pháp & Kết quả Đạt được
1. Tối ưu Engine Content (GPT-4o-mini & JSON Mode) Tích hợp mô hình gpt-4o-mini qua OpenAI API với tùy chọn Response Format: JSON Object. Phản hồi siêu tốc (1-2 giây), chi phí cực rẻ (~18 VNĐ / 1 lượt call API), tự động phân rã 3 bài viết theo đúng 3 phong cách (Chuyên gia/Kỹ thuật, Cảm xúc/Trải nghiệm, B2B Action) mà không bị lỗi dính code markdown rác.
2. Hỗ trợ Đa Ảnh cho 1 Slide (Multi-Image per Slide) Nâng cấp node AI Tự chọn ảnh và Tách ảnh từ nhiều link để truyền mảng dữ liệu raw_image_ids và raw_image_names (tối đa 2 ảnh/slide, ví dụ: Style 6 với 1 ảnh dọc to + 2 ảnh vuông xếp chồng). Bảo toàn dữ liệu Binary xuyên suốt luồng pipeline.
3. Tinh chỉnh Prompt Builder & Chỉ dẫn Cắt Ảnh (Cropping Rules) Tái cấu trúc node Prompt Builder bổ sung quy tắc linh hoạt: "AI ĐƯỢC PHÉP tự do cắt hình, tách nền, xén tỷ lệ (crop) hoặc điều chỉnh kích thước ảnh thô". Gom gọn chỉ dẫn đính kèm 1 hoặc nhiều ảnh Binary, tự động tính toán orientation (ảnh ngang/dọc/vuông) và bóc tách từ khóa nhấn mạnh.
4. Tự động hóa Khối Thương Hiệu & Thông tin Liên hệ (Signature & Footers) Tự động loại bỏ nhãn thừa AI, gỡ bỏ lỗi lặp tên thương hiệu (chỉ giữ đúng "Ecolar"), tự động gắn danh sách Hashtags chuẩn và chèn khối thông tin liên hệ đa kênh (Website, Hotline 0868 515 668, Zalo OA, Fanpage, Youtube, Tiktok) đồng bộ 100% ở cuối mỗi bài viết.
5. Node Chuẩn hóa Dữ liệu Google Sheet Đa Nguồn Viết lại node Code chuẩn hóa 3 Options hỗ trợ đọc trực tiếp cấu trúc JSON đa dạng từ OpenAI (`j.content[0].text`), Gemini API (`j.candidates`), cũng như Groq. Bóc tách dữ liệu mượt mà, trả về 5 trường thông tin chuẩn cho Google Sheet: Option_1, Option_2, Option_3, Anh_Demo và Trạng thái: waiting_review.

3. QUY CHUẨN ĐỒ HỌA THƯƠNG HIỆU & KHÓA BỐ CỤC ALBUM

Hệ thống tự động đọc tiêu chuẩn kích thước từ Google Sheet và gán chỉ dẫn chi tiết cho mô hình AI Gen Ảnh:

Nhóm Style Quy chuẩn Bố cục Ảnh Chỉ dẫn AI Gen Ảnh (Visual Brief Rules)
Bài 1 Ảnh Style 1 (1200x1200px) 1 Ảnh vuông duy nhất, bố cục chữ nhật bo góc chiếm 1 nửa khung. Nền xanh đặc (#056823).
Bài 2 Ảnh Style 2 / 3 Ghép 2 ảnh đứng (600x1200px) hoặc 2 ảnh ngang (1200x600px). Bố cục circle-mask chỉ dùng khi so sánh trước/sau.
Bài 3 Ảnh Style 6 (Bìa + 2 ô) 1 Cột dọc to bên trái (600x1200px) + 2 ô vuông xếp chồng bên phải (600x600px). Lồng ghép 2 ảnh thô linh hoạt.
Phân vùng Safe Zone Logo Top-Left Chừa trống góc TRÊN-TRÁI (15-18% chiều rộng x 10-12% chiều cao) để hệ thống tự ghép Logo Ecolar sau.
